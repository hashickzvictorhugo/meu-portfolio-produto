
## Loop Verification Rules
- Toda nova feature ou correção deve ser validada via TestSprite.
- A conclusão de uma tarefa exige a execução do comando `testsprite test run --all`.
- Falhas no TestSprite devem ser analisadas via failure bundle antes de qualquer nova tentativa de correção.
- O estado do projeto deve ser atualizado em `progress.md` após cada iteração do loop.
