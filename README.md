Bem-vindo ao repositório do meu portfólio pessoal. Este projeto foi desenvolvido para ir além de uma simples página estática, entregando uma experiência imersiva com estética cyber-terminal, animações de partículas e interações dinâmicas.

---

## Funcionalidades em Destaque

- **Estética Cyber-Terminal:** Design dark, minimalista e focado na imersão do usuário.
- **Modo Terminal Interativo:** Navegação e comandos simulando um ambiente de linha de comando real.
- **Chatbot Integrado:** Um assistente virtual para interagir com os visitantes de forma dinâmica.
- **Media Player:** Integração fluida para reprodução de mídia diretamente na interface.
- **Animação de Partículas:** Efeitos visuais de fundo que reforçam a identidade tecnológica do projeto.
- **Totalmente Responsivo:** Construído com Tailwind CSS para rodar perfeitamente em qualquer dispositivo (mobile ou desktop).

---

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes ferramentas:

- **HTML5 & CSS3:** Estruturação e estilização base.
- **JavaScript (Vanilla):** Lógica do chatbot, modo terminal, media player e controle das partículas.
- **Tailwind CSS:** Framework utilitário para agilizar e padronizar o design responsivo.
- **Vercel:** Plataforma escolhida para hospedagem e deploy contínuo (CI/CD).
